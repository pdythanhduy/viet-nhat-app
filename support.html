Viet Nhat app support page

Viet Nhat is an information app for Vietnamese users living in Japan.

Support Contact

Email: thanhduy8vn@gmail.com

Main App Areas

  • Administrative guides and visa-related procedures
  • Labor rights, jobs, tax, pension, and insurance basics
  • Daily life guidance in Japan
  • Japanese language support for practical situations
  • Optional AI chat using a user-provided Anthropic API key

Important Notes

  • The AI feature is optional and does not work unless the user enters their own API key.
  • The app does not issue or sell AI API keys.
  • Most saved data is stored locally on the user's device.
  • The app uses local notifications only for reminder dates created by the user.
