- [ ] Google Play feature graphic

## 3. Recommended Screenshot Set

Take 5 screenshots first. That is enough for a clean first submission.

1. Home
   - show categories, important updates, and the cleaned `Gia đình / visa` area
2. Thủ tục
   - show the admin guides list or a high-value guide detail screen
3. Việc làm
   - show labor rights / complaint guidance / labor handbook entry points
4. Cuộc sống hằng ngày
   - show search, quick filters, and grouped practical topics
5. Tiếng Nhật
   - show phrases or practice flow

## 4. Screenshot Rules To Keep Them Clean

- Use one language consistently across all screenshots
- Avoid showing placeholder or obviously test-only content
- Avoid empty states unless the empty state is itself a feature being marketed
- Use a realistic reminder date instead of fake nonsense data
- If AI is shown, do not show exposed API keys
- Prefer bright, stable screens over modals or half-complete forms

## 5. Feature Graphic For Google Play

Recommended concept:

- App name: `Viet Nhat`
- Simple line: `Hướng dẫn thực tế cho người Việt tại Nhật`
- Use the app's blue as the primary brand color
- Avoid overcrowding many small screenshots into one banner

## 6. Order To Capture Screenshots

1. Seed realistic local data:
   - one or two saved items
   - one important date
   - a few completed checklist items
2. Open each target screen
3. Hide any sensitive personal information
4. Capture portrait screenshots
5. Save filenames clearly:
   - `ios-home-67.png`
   - `ios-admin-67.png`
   - `android-home-phone.png`

## 7. Final Pre-Capture Checks

- [ ] No mojibake or broken Vietnamese text
- [ ] No clipped text on small screens
- [ ] No debug overlays
- [ ] No empty API key text visible
- [ ] No temporary sample dates that look fake
- [ ] Visual hierarchy is readable on first glance
