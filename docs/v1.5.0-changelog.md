## User-facing improvements

### Smarter search

- Search ranks Japanese terms, romaji, and Vietnamese keywords as distinct layers — you get the right guide first, not the one that happened to mention the word in a footnote
- `zairyu card`, `quá hạn visa`, `rikon`, `永住`, `juminzei` and dozens of similar queries now return the correct top result on the first try

### Related guides

- Every guide detail page now suggests 3-4 related guides at the bottom — including across categories where the topics naturally link (e.g., overstay → visa extension, residence card loss, lawyer consultation)
- Suggestions are computed from shared keywords, not a hand-maintained list, so coverage stays consistent as new guides ship

### "Hay được dùng" — featured guides on Home

- New horizontal row of editorially-selected high-impact guides between "Cho người mới sang Nhật" and the policy-update section
- Same featured guides appear when search is empty or returns no results, so users always have somewhere useful to go

### Better emergency discoverability

- "Cần hỗ trợ gấp?" call-to-action surfaces in the search empty + no-results states — one tap reaches the Emergency Hub
- Featured guides are visible without typing anything

### Content depth — newcomer onboarding

- "7 ngày đầu", "30 ngày đầu", "90 ngày đầu" guides now surface in more searches with terms newcomers actually type ("moi sang nhat", "first week japan", "checklist thang dau")
- SIM card guide searchable by carrier name (Rakuten, Docomo, Softbank, Ahamo, Povo) and by `eKYC` keyword
- 転入届 / moving-in notification searchable by both JP form and `tennyu todoke` romaji

### Trust & compliance

- 127 admin guides verified within the last 23 days
- Every guide cites its official source (出入国在留管理庁 / 厚生労働省 / 法務省 / etc.)
- No "guaranteed pass" or "loophole" language anywhere — ambiguous cases defer to 弁護士 / 行政書士 / 法テラス

---

## Under-the-hood improvements

- Search index pre-normalized at module load — no re-tokenization on every keystroke
- Featured guides memoized at screen level — no re-computation on input change
- Analytics layer adds aggregate-only search metrics (24-char normalized, no raw queries leave the device) so we can mine which topics users struggle to find — without ever storing identifying input

### Long version (≤ 4000 chars)

**Tiếng Việt**

Phiên bản này tập trung vào việc tìm kiếm và phát hiện guide.

- **Tìm kiếm thông minh hơn**: Gõ "zairyu card", "quá hạn visa", "rikon" hay "住民税" — bạn sẽ nhận guide đúng ngay từ kết quả đầu tiên, thay vì phải dò qua nhiều mục.
- **Gợi ý guide liên quan**: Mỗi trang guide bây giờ hiển thị 3-4 guide có liên quan ở cuối — kể cả khi chúng nằm ở chuyên mục khác. Ví dụ: mở guide overstay → thấy ngay guide gia hạn visa, mất thẻ cư trú, tư vấn 法テラス.
- **"Hay được dùng" trên Trang chủ**: Một hàng các guide quan trọng nhất, dễ thấy trước khi gõ bất kỳ từ khóa nào.
- **Truy cập khẩn cấp dễ hơn**: Khi tìm kiếm không có kết quả, bạn vẫn thấy guide quan trọng + lối tắt đến Trung tâm khẩn cấp ngay trên màn hình.
- **Bổ sung từ khóa cho người mới sang Nhật**: Các guide 7/30/90 ngày đầu, đăng ký SIM, đăng ký địa chỉ (転入届) nay tìm thấy nhanh hơn với nhiều cách gõ khác nhau — kể cả romaji hoặc tiếng Việt không dấu.
- **Nội dung đã kiểm tra**: 127 guide hành chính được rà soát trong vòng 23 ngày qua, dẫn nguồn chính thức từ 出入国在留管理庁, 厚生労働省, 法務省 và các cơ quan liên quan.

Phiên bản này không thêm tính năng mới đòi quyền truy cập nào. Không gửi nội dung tìm kiếm gốc về server — chỉ có dữ liệu tổng hợp đã chuẩn hóa ngắn gọn, không chứa thông tin cá nhân.

**English**

This release focuses on search and guide discovery.

- **Smarter search**: Type "zairyu card", "quá hạn visa", "rikon", or "住民税" — you get the right guide as the top result, not buried in a list.
- **Related guide suggestions**: Every guide page now shows 3-4 related guides at the bottom, including cross-category links (e.g., overstay → visa extension, residence card loss, 法テラス legal aid).
- **"Hay được dùng" on Home**: A row of high-impact guides surfaces before you even type anything.
- **Faster path to emergency help**: When search returns no results, you still see featured guides + a direct link to the Emergency Hub.
- **Newcomer keyword coverage**: First-7/30/90-days, SIM registration, address registration (転入届) guides now match more search forms — romaji, Vietnamese without diacritics, and Japanese terms.
- **Verified content**: 127 admin guides reviewed within the last 23 days, citing official Japanese government sources.

No new permissions. No raw search content leaves your device — only short, normalized aggregate keywords are forwarded, with no personal information.
