## Why this doc exists

v1.5.0 ships meaningful discovery improvements (smarter ranking, related guides, featured guides, emergency CTA on search). If the App Store screenshots and description still reflect v1.3/v1.4 UI, users see one app in the store and a noticeably better one after install — bad first impression, and a missed conversion lever.

This doc captures what to audit and what to propose. The actual asset work is a separate task gated by the audit result.

---

## 1. What to audit (do this before drafting new assets)

### A. App Store / Play Store screenshots

Pull the screenshots from each store listing and check each against the current build:

- **Home screen**: Does the v1.4 screenshot show the same sections? After v1.5.0 there's a new "Hay được dùng" featured row — visible on Home. If the screenshot shows the v1.3/v1.4 Home layout, it's stale.
- **Admin guide list**: Should still match — category grid layout is unchanged.
- **Admin guide detail**: Does the screenshot show a guide with the bottom "Xem thêm liên quan" section? If not, it's pre-Phase-2B and stale.
- **Search**: Critical surface — if old screenshot shows the bare empty-state chips without featured guides + emergency CTA, it's strictly worse than v1.5.0 reality.
- **Japanese / Jobs**: Should be stable across v1.4 → v1.5.
- **Daily Ritual**: Unchanged.

For each screenshot, classify: **OK / Stale / Misleading**.

### B. App description text

Current App Store description (Vietnamese + English if dual-locale) — read in full and flag:

- Any mention of features that don't exist (e.g., "AI-powered" if AI Mail isn't shipped)
- Any mention of features that DO exist but aren't called out (smart search, related guides)
- Any wording that's vague where it could be concrete (e.g., "many guides" → "127 verified admin guides")
- Any wording that overpromises ("guaranteed" / "tăng tỷ lệ đậu" / "loophole") — should not exist per compliance rules

### C. Keywords / search optimization

App Store / Play Store search keyword fields:

- Are the high-intent terms covered: `zairyu`, `visa`, `cẩm nang`, `Nhật Bản`, `thủ tục`, `永住`, `在留カード`?
- Vietnamese diacritic vs no-diacritic — Apple's ASO doesn't dedupe, so cover both forms
- Are competitor-style keywords like "japan life", "japan visa" covered?

### D. App icon / brand

- App icon unchanged in v1.5.0 — no audit needed unless redesign proposed elsewhere
- Splash screen unchanged
- Display name: "Cẩm Nang Việt Nhật" — unchanged

Vietnamese locale field:
```
visa,nhat ban,cam nang,thu tuc,zairyu,nenkin,my number,sumai,bao hiem,viec lam,tieng nhat
```

(99 chars — Apple counts commas)

```
japan,visa,vietnamese,residency,nenkin,zairyu,my number,immigration,japanese,life japan
```

(94 chars)

Play Store doesn't have a separate keyword field — keywords are mined from description. Description should organically contain the same terms.

## 5. Compliance check on copy

Before any asset ships, verify the description does NOT contain:

- "guaranteed" / "đảm bảo" / "100% đậu" — anywhere
- "tăng tỷ lệ đậu" / "mẹo kháng cáo" / "lách luật" / "loophole" — anywhere
- "tư vấn cá nhân" / "luật sư miễn phí" — we are not a law firm
- "AI" / "AI-powered" — AI Mail is hidden, do not advertise
