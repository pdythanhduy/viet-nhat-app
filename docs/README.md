# Public Docs

This folder contains static HTML pages prepared for public hosting:

- `support.html`
- `privacy-policy.html`
- `terms.html`

Recommended use:

1. publish this `docs/` folder with GitHub Pages, Netlify, Vercel static hosting, or another static host
2. copy the final public URLs into:
   - App Store Connect
   - Google Play Console
   - `STORE_METADATA_DRAFT.md`
   - `RELEASE_CHECKLIST.md`

If you use GitHub Pages from the repository root, this folder is already in a convenient format for direct publishing.
