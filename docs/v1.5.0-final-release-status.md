## Discovery improvements

1. **Layered search ranking** — JP `titleJp` matches (+120/+80/+60) outrank keyword matches (+50/+35) which outrank body text (+8). Editorially-flagged guides get a +6 nudge
2. **`getRelatedGuides`** — cross-category token-overlap scoring renders at bottom of every guide detail
3. **`getFeaturedGuides`** — 42 `priority: 'high'` guides surface as "Hay được dùng" horizontal row on Home + as fallback on Search empty/no-results states
4. **Emergency CTA on search** — "Cần hỗ trợ gấp?" card always reachable from search when results are empty
5. **Newcomer keyword coverage** — first-week guides searchable by `tennyu todoke`, `sim`, `eKYC`, `ahamo`/`povo`/`docomo`/`softbank`/`rakuten mobile`, `first week japan`, `checklist tuan dau`, etc.

Before/after ranking deltas (pinned by `src/utils/searchIndex.test.ts`):
- `zairyu card` → `residence-card-validity` (was: generic policy update)
- `quá hạn visa` → `overstaying-illegal-stay-procedures` (was: student visa guide)
- `rikon` → `divorce-custody-name-residence` (was: residence-card info change)

## Retention improvements

1. **"Đã xem gần đây" Home section** — last 5 admin guides opened, newest-first, deduped, hidden when empty
2. **Storage util** at `src/utils/recentlyViewedGuides.ts` reusable for future surfaces (badge in search results, daily-guide exclusion, etc.)
3. **Source tracking** — `guide_open` now distinguishes `search` / `related` / `featured` / `direct` / `recent_viewed`, so post-launch we can measure which surface earns its place

Phase 2C (Surface 2 reminders + Surface 3 daily guide) **intentionally deferred** to post-launch analytics — see `docs/retention-phase-proposal.md`.

- No user-typed strings other than the normalized 24-char form
- Aptabase EU instance (privacy-friendly default)
