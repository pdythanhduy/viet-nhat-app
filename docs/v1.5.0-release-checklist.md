# v1.5.0 — Release Checklist

**Target submission**: when this list is fully checked.
**Owner**: pdythanhduy.
**Branch**: `chore/v1.5.0-release-prep`.

This is a gate, not a guide. Don't submit to App Store until every item is ✅ or has a written waiver.

---

## 1. Smoke test (real device, both platforms if possible)

Follow [`docs/search-discovery-phase2b-smoke-test.md`](search-discovery-phase2b-smoke-test.md). Plus:

- [ ] App launches cold from home screen in under 4s
- [ ] Tab navigation between Home / Admin / Jobs / Japanese / Saved — no crash, no white flash
- [ ] Open and close `AdminDetail` for at least 5 different guides — no leak/stutter on back nav
- [ ] Daily Ritual: tap "Bắt đầu" → answer 3 → finish → streak increments
- [ ] Bookmark a guide → close app → reopen → bookmark persists
- [ ] Search empty + no-results states render the new featured guides surface (Phase 2B)
- [ ] Featured guide tap fires `guide_open { source: 'featured' }` in Metro log
- [ ] Related guide tap fires `guide_open { source: 'related' }`
- [ ] Search result tap fires `guide_open { source: 'search' }`
- [ ] Direct nav (bookmark, onboarding card) fires `guide_open { source: 'direct' }`

## 2. Analytics verification

- [ ] `app.json → expo.extra.aptabaseAppKey` is set to a real key (not placeholder)
- [ ] In dev, opening 5 different surfaces produces 5 distinct `[analytics]` log lines with correct event names
- [ ] `search_query` event NEVER contains diacritics, mixed case, or >24-char strings (PII guard)
- [ ] `search_no_results` fires only when result_count === 0
- [ ] `guide_open` always carries a `source` field (none undefined)

## 3. App Store metadata check

Reference: [`docs/v1.5.0-app-store-audit.md`](v1.5.0-app-store-audit.md). Specifically:

- [ ] App version in `app.json` and `package.json` both say `1.5.0`
- [ ] `expo.ios.buildNumber` incremented from last submission
- [ ] `expo.android.versionCode` incremented from last submission
- [ ] Bundle identifier unchanged
- [ ] App icon unchanged (or if changed, new icon committed)
- [ ] Splash screen unchanged
- [ ] App name display unchanged
- [ ] Permissions list unchanged (no new camera/location/contacts requests)

## 4. Hidden feature verification

These MUST stay hidden:

- [ ] AI Mail (Dịch Thư Nhật) — no Home/Settings entry point. Routes registered but unreachable
- [ ] My Japan Plan (#35) — no Home exposure, no nav entry
- [ ] JLPT — protected dataset, no menu entry
- [ ] No debug screens in nav

Grep before submitting:
```
grep -rn "MailCapture\|MailTranslate" src/screens/HomeScreen.tsx src/screens/home/
grep -rn "MyJapanPlan\|PersonalPlan\|JourneyChecklist" src/screens/HomeScreen.tsx
```
Both must return only the gating comment, not a render path.

## 5. Navigation sanity

- [ ] Back navigation from every route returns to the expected parent
- [ ] Deep link (if any) opens the correct route
- [ ] Modal screens (`ProfileSetupModal`, etc.) dismiss cleanly without leaving residue
- [ ] No screen shows a blank state during normal navigation

## 6. Performance sanity

- [ ] Cold launch < 4s on a mid-range Android device
- [ ] Home → tap any guide → AdminDetail render in < 1.5s
- [ ] Search input → first results render in < 500ms for cached index
- [ ] No dropped frames during scroll of long guides
- [ ] No console errors / warnings in dev mode beyond the documented Aptabase-key-missing warning

## 7. Offline behavior

Test with airplane mode ON:
- [ ] App opens and shows Home
- [ ] Guides render (content is bundled)
- [ ] Bookmarking still works (local storage)
- [ ] Search still works (index is local)
- [ ] Tapping an `officialLinks` URL shows a clean "không thể mở link" alert, not a crash
- [ ] Mail Translate (if anyone reaches the hidden routes) handles offline gracefully

## 8. Final pre-submit

- [ ] `npm run verify` (typecheck + tests + content audit) is clean on main
- [ ] No uncommitted local changes on `main` branch  
- [ ] Git tag `v1.5.0` created and pushed
- [ ] Changelog committed: [`docs/v1.5.0-changelog.md`](v1.5.0-changelog.md)
- [ ] App Store release notes finalized (EN/VI from changelog doc)
- [ ] EAS build triggered with the v1.5.0 tag as the source ref

## 9. Post-submit

- [ ] Submission ID captured in changelog
- [ ] Apple/Google review status monitored
- [ ] Rollback plan if rejection: revert to v1.4.0 tag `d590a5a`, address feedback in a v1.5.1
