## 6. Failure capture instructions

For any row that fails:

1. **Screenshot** the visible state on device
2. **Copy** the last 20 lines of Metro log
3. **Note** the platform (iOS / Android), OS version, and device model
4. **Comment on the PR** (or open a new issue) with: row number + screenshot + log snippet + repro steps

### Severity gates

| Severity | Definition | Action |
|---|---|---|
| **Blocker** | App crashes, white screen, infinite loader, lost user data | DO NOT submit to App Store. Fix on a `fix/v1.5.0-*` branch, merge, re-build |
| **High** | Wrong analytics event, broken nav, missing section that should appear | Investigate before submit; may submit if isolated and documented |
| **Medium** | Visual glitch, off-by-one in recent-viewed order, slow render (> 4s cold start) | Submit if shipping deadline is hard; fix in v1.5.1 |
| **Low** | Cosmetic copy issue, icon alignment, missing accessibility label | Submit as-is; track for v1.5.1 |
